# Ultrasi.io

A Metaversal Arts research landing page about intelligence developed through experience, in collaboration with UltraSim.io.

## Site

Buildless HTML, CSS, JavaScript, and SVG in `dist/`. No installation or build step is required. No external fonts, analytics, application cookies, or server-submitted contact form.

- A large purple, star-filled “Ultrasi” slider, adapted as a playful visual metaphor from the supplied reference.
- Project vision, proposed research loop, UltraSim collaboration, and open research questions.
- Locally prepared email enquiries with Gmail, email-app, and clipboard choices.
- Shared operator details, legal notice, and privacy information.

Ultra super intelligence is a long-term ambition, not a demonstrated capability. The page does not present a working AI model or automated transfer pipeline. Private implementation material and research documents are excluded.

## Local preview

Run `node preview.mjs` and open the printed localhost URL. The preview server binds only to loopback.

## Hosting

GitHub Pages publishes only `dist/` through `.github/workflows/pages.yml`. The intended domain is `ultrasi.io`, registered with Namecheap. See `DEPLOYMENT.md` for the verified deployment state.

The ignored `.openai/hosting.json` records an unused private Sites registration made before GitHub Pages was selected. It is not the hosting configuration for this project.
